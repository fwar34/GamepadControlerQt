# 变更记录 · GamepadControlerRustIced

本次改造（2026-08-27）记录如下。后续如有新改动，继续在下方追加。

## 悬浮窗独立窗口化
- 单窗口 `application` 改造为 `iced::daemon` 多窗口：主窗口 + 独立悬浮窗（`src/main.rs`、`src/ui/app.rs`）
- 悬浮窗：置顶、无边框、半透明；透明度 20%~100% 可在主界面滑杆实时调节
- 悬浮窗标题栏按住可拖动（`window::drag`）
- 悬浮窗内可展开/收起当前层映射
- 仅关闭悬浮窗不影响主程序

## 退出逻辑
- "退出"按钮改用 `iced::exit()` 终止整个应用
- 监听 `close_events`：关闭主窗口 → 程序整体退出（悬浮窗一并关闭）；关闭悬浮窗 → 仅清理状态

## 悬浮窗按键显示
- "无按键按下"与按键 chip 统一内边距，避免两种状态高度不一致导致下方内容被挤动（`src/ui/overlay.rs`）
- 从 200ms 固定轮询改为**事件驱动即时刷新**：手柄线程在按键/连接状态变化时通知 UI 立即重绘，快速按键也能跟手对应（`src/ui/shared.rs` 新增通知通道、`src/ui/app.rs` 新增订阅流）

## 字体渲染优化（不修改第三方源码）
- 尝试过：vendored iced_graphics 禁用 hinting（已按用户要求回滚，不保留）
- 最终方案：
  - 用 fontTools 将系统 Noto Sans SC 可变字体实例化为**静态 Regular TTF**（去除 gvar/fvar 可变轮廓、固定字重 400），规避可变字体在部分复杂字形（如"重"、"悬"）上的渲染异常
  - 字体文件 `fonts/NotoSansSC-Regular.ttf`（OFL 开源授权）通过 `include_bytes!` 内嵌进 exe，程序自包含、不依赖系统字体
  - 全局字号提高一档：10→11、11→12、12→13、13→14、14→15、16→17（大标题 20 保持不变），字形更大更平滑
